# 운영 가이드

회원에게 이 사이트를 어떻게 쓰게 할지, 트레이너가 뭘 조정해야 하는지 정리한 문서입니다.

---

## 1. 상담에서 쓰는 순서

숫자만 던지면 회원은 따라오지 못합니다. 화면 순서대로 설명하세요.

1. **지금 상태** — 기초대사량과 총 대사량이 얼마인지. "가만히 있어도 이만큼 쓴다"
2. **목표 섭취량** — 왜 이 칼로리인지. 다이어트는 총 대사량보다 적게, 기초대사량보다는 많게
3. **오늘 실행** — 끼니별 배분표. "한 끼에 이 정도"
4. **주간 변화** — 1~2주 뒤 체중 추세를 보고 다시 조정한다는 것을 미리 알려주기

목적은 정해진 식단을 그대로 먹이는 게 아니라,
회원이 자기 섭취량을 이해하고 혼자서도 조절할 수 있게 만드는 것입니다.

---

## 2. 회원에게 안내할 입력 요령

| 항목 | 안내 |
|---|---|
| 인바디 기초대사량 | 있으면 꼭 입력. 추정식보다 정확합니다 |
| 활동 수준 | 운동 횟수보다 **하루 전체 활동량**으로 판단. 앉아서 일하면 주 3회 운동해도 '보통' |
| 목표 체중 · 기간 | 선택 사항이지만, 넣으면 속도가 현실적인지 자동으로 검증됩니다 |
| 식사 횟수 | 실제 생활 패턴대로. 3끼면 3끼로 |

단백질 · 지방 기준(g/kg)과 칼로리 직접 조정은 `인바디 값이 있거나, 직접 조정하고 싶다면`
항목을 펼치면 나옵니다. **트레이너가 판단해서 바꾸는 값**입니다.

---

## 3. 2주 뒤 재조정 기준

첫 2주는 그대로 해 보게 하고, 그다음에 조정합니다.

| 관찰 | 조치 |
|---|---|
| 체중이 예상보다 훨씬 빨리 줄고, 컨디션 · 훈련 수행이 떨어짐 | 섭취량을 올린다 (칼로리 직접 조정을 +100~200) |
| 변화가 없는데 식단 준수율은 충분함 | 소폭 낮춘다 (−100~150) |
| 준수율이 낮음 | 칼로리를 건드리지 말고 **식단 구성**을 먼저 바꾼다 (PLAN 교체 또는 축 식품 교체) |
| 주당 변화가 체중의 1%를 넘음 | 기간을 늘리고 조정 폭을 줄인다 |

한 번에 하나씩만 바꾸세요. 두 개를 동시에 바꾸면 뭐가 효과였는지 알 수 없습니다.

---

## 4. PLAN 고르는 기준

| 회원 유형 | 추천 |
|---|---|
| 무난하게 시작 · 집밥 위주 | **PLAN A 한식 기본형** |
| 밥이 부담스럽거나 소화가 더딤 · 준비 시간이 짧아야 함 | **PLAN B 고구마 · 생선형** |
| 아침에 시간이 없음 · 간편식 필요 | **PLAN C 오트밀 · 소고기형** |

세 안 모두 축 식품(탄수화물원 · 단백질원 · 지방원)을 음식 DB의 다른 식품으로 바꿀 수 있습니다.
회원이 싫어하는 식품이 있으면 그 자리에서 바꿔 보여주세요.

**주의** — 지방이 많은 단백질원(연어 · 고등어 · 돼지 등심 등)으로 바꾸면
지방이 먼저 채워져 오일이 0g이 되고 총 칼로리가 목표를 넘습니다.
화면에 경고가 뜨니, 그럴 땐 탄수화물원 양을 줄이거나 지방이 적은 단백질원으로 안내하세요.

---

## 5. 채소 · 양념은 계산에 없습니다

식단 3안의 합계에는 **양념 · 소스 · 국물 · 추가 채소**가 들어있지 않습니다.
기름과 설탕이 들어가는 양념은 실제로 하루 100~200kcal씩 차이를 만듭니다.
회원에게 이 점을 반드시 말해 주세요.

김치 · 나물 등 채소는 자유롭게 먹되, 볶거나 무친 것은 기름이 붙는다는 것만 짚어 주면 됩니다.

---

## 6. 이런 회원은 이 계산기를 쓰지 마세요

- 신장질환 · 당뇨 · 심혈관 질환 등으로 식이 제한을 받는 경우
- 임신 · 수유 중
- 섭식장애 이력이 있거나 의심되는 경우
- 약물치료 중이라 식사와 상호작용이 있는 경우
- 만 18세 미만 성장기

이 경우는 의료진 · 영양사의 개별 지도가 우선입니다.
계산기가 내놓는 숫자를 근거로 식사량을 제한하도록 안내하지 마세요.

---

## 7. 회원 기록 보기

회원이 계산기를 쓰면 이름 · 연락처 · 마지막 계산 결과가 자동으로 쌓입니다.

### 다만 전부 쌓이지는 않습니다

시작 화면에는 `동의하고 시작하기` 와 `건너뛰고 바로 쓰기` 두 버튼이 있습니다.
**건너뛴 사람은 명단에 안 뜹니다.** 서버와 아예 통신하지 않기 때문입니다.

명단 수가 실제 사용자 수보다 적은 게 정상입니다. 이름을 남기게 하려면
링크를 뿌릴 때 "결과를 트레이너가 보고 다음 상담 때 이어서 봐준다"는 걸 같이 알려주세요.
그게 이름을 남길 이유가 됩니다. 버튼을 없애서 강제하는 것보다 이쪽이 이탈이 적습니다.

건너뛴 사람도 화면 위에 `이름 남기기` 버튼이 계속 떠 있고,
나중에 누르면 **그때까지 계산한 결과까지 같이 전송**되므로 다시 계산할 필요가 없습니다.

### 보는 곳

배포 주소 뒤에 `/admin.html` 을 붙입니다.
예: `https://nutrition-guide.pcbpcb1990.workers.dev/admin.html`

관리자 키를 넣으면 명단이 열립니다. 이름 · 연락처로 검색되고,
`엑셀(CSV) 내려받기` 를 누르면 그대로 엑셀에서 열 수 있습니다.

### 꼭 지켜야 할 것

- **공용 PC에서는 사용 후 `잠그기`를 누르세요.** 안 누르면 그 탭에서 계속 열립니다
  (탭을 닫으면 자동으로 풀립니다)
- 관리자 키는 카톡·메모장에 남기지 말고 비밀번호 관리 앱에 두세요.
  이 키 하나로 전 회원의 이름과 연락처가 열립니다
- 내려받은 CSV 는 그 자체가 개인정보 문서입니다. 다 쓴 파일은 지우세요
- 회원이 삭제를 요청하면 명단에서 그 줄의 `삭제` 를 누르면 즉시 지워집니다

### 회원이 직접 지우는 방법

회원 화면 위쪽 초록 띠의 `내 기록 삭제` 를 누르면 본인 기록이 DB에서 바로 삭제됩니다.
동의를 철회하고 싶어 하는 회원에게는 이 버튼을 안내하면 됩니다.

### 같은 회원인데 두 줄로 보인다면

기록은 **브라우저 단위**로 잡힙니다.
회원이 휴대폰으로 한 번, PC로 한 번 하면 이름이 같아도 두 줄이 됩니다.
필요 없는 줄은 `삭제` 로 정리하세요.

## 8. 값 수정 · 배포

음식이나 계수를 바꾸려면 `README.md` 의 표를 참고해서 `public/data/` 안의 파일을 고치고,
아래로 배포합니다.

```bash
npx wrangler deploy
```

정적 파일뿐이라 빌드 과정은 없습니다. 저장 → 배포로 끝입니다.
