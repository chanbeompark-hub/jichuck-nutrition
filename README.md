# 🥗 NUTRITION GUIDE — 내 식단 칼로리 계산기

회원이 직접 나이 · 키 · 체중 · 활동량을 입력하면
**하루 목표 칼로리와 탄수화물 · 단백질 · 지방의 양**, 그리고 그것을 채우는
**맞춤 식단 3안**까지 자동으로 만들어 주는 공개용 웹사이트입니다.

빌드 도구 없는 정적 사이트입니다. HTML / CSS / JS 파일만 있고,
Cloudflare Workers 정적 호스팅으로 배포합니다.

원본은 `회원_식단_자동설계_통합관리_음식DB_150개확장.xlsx` 이며,
그 파일의 계산 로직(회원설정 · 자동식단설계 · 자동식단3안 · 영양가이드 시트)과
음식 DB 181종을 그대로 웹으로 옮겼습니다.

## 계산 방식

### 1. 기초대사량 (BMR)

인바디 값을 입력하면 그 값을 쓰고, 없으면 **Mifflin-St Jeor 식**으로 추정합니다.

```
남성: 10 × 체중(kg) + 6.25 × 키(cm) − 5 × 나이 + 5
여성: 10 × 체중(kg) + 6.25 × 키(cm) − 5 × 나이 − 161
```

### 2. 총 대사량 (TDEE) = BMR × 활동계수

| 활동 수준 | 계수 | 기준 |
|---|---|---|
| 낮음 | 1.25 | 거의 앉아서 생활 · 운동 없음 |
| 보통 | 1.40 | 주 2~3회 운동 |
| 높음 | 1.55 | 주 4~5회 운동 · 활동적인 직업 |
| 매우높음 | 1.70 | 주 6회 이상 · 육체노동 병행 |

### 3. 목표 칼로리 = TDEE + 조정값

| 목표 | 조정값 | 단백질 기본 | 지방 기본 |
|---|---|---|---|
| 다이어트 | −400 kcal | 1.8 g/kg | 0.8 g/kg |
| 유지 | 0 kcal | 1.6 g/kg | 0.9 g/kg |
| 증량 | +250 kcal | 1.6 g/kg | 1.0 g/kg |

### 4. 탄단지

```
단백질(g) = 체중 × 단백질 기준(g/kg)
지방(g)   = 체중 × 지방 기준(g/kg)
탄수화물(g) = (목표 kcal − 단백질×4 − 지방×9) ÷ 4
```

### 5. 식단 3안 자동 설계

각 PLAN 은 **고정 식품**(양이 정해진 것)과 **축 식품 3개**(탄수화물원 · 단백질원 · 지방원)로
구성되고, 축 식품의 양을 순서대로 풀어 목표 영양소를 채웁니다.

1. 고정 식품이 주는 탄수화물을 빼고, 남은 탄수화물을 **탄수화물원**으로 채운다
2. 거기서 따라온 단백질까지 빼고, 남은 단백질을 **단백질원**으로 채운다
3. 마지막으로 남은 지방을 **지방원**으로 채운다

세 축 식품은 화면에서 음식 DB의 다른 식품으로 바꿀 수 있고, 바꾸는 즉시 다시 계산됩니다.
지방이 많은 단백질원(연어 · 고등어 등)을 고르면 지방이 먼저 채워져 오일이 0g이 되고
총 칼로리가 목표를 넘는데, 이 경우 화면에 경고와 대안이 함께 표시됩니다.

### 6. 안전장치

다음 상황에서는 결과와 함께 경고를 띄웁니다.

- 목표 칼로리가 기초대사량보다 낮을 때
- 남성 1,500 / 여성 1,200 kcal 미만일 때
- 주당 체중 변화가 현재 체중의 1%를 넘을 때
- 목표 기간이 요구하는 속도와 실제 섭취량의 예상 속도가 어긋날 때
- 탄수화물이 단백질보다 적게 계산될 때
- 입력한 인바디 값이 추정식과 20% 이상 차이 날 때

## 개인정보

입력값은 **브라우저 localStorage 에만** 저장되고 서버로 전송되지 않습니다.
백엔드도 데이터베이스도 없습니다. `처음 값으로` 버튼을 누르면 저장된 값이 지워집니다.

## 로컬에서 보기

```bash
npx wrangler dev --config nutrition-planner/wrangler.jsonc --port 8789
```

`http://localhost:8789` 로 열립니다.

## 배포

```bash
npx wrangler deploy
```

`wrangler.jsonc` 의 `name` 이 `nutrition-guide` 이므로
`https://nutrition-guide.<계정>.workers.dev` 로 올라갑니다.

배포 후 `public/robots.txt` 와 `public/sitemap.xml`, `index.html` 의 `canonical`
주소를 실제 도메인으로 바꿔 주세요.

|---|---|

| 경고 기준 (칼로리 하한 등) | `public/assets/js/app.js` 의 `renderWarnings` |

## 출처와 면책

영양성분 값은 국가표준식품성분표(<https://www.nics.go.kr/food/>)와
USDA FoodData Central(<https://fdc.nal.usda.gov/>)의 대표값입니다.
품종 · 브랜드 · 수분량 · 조리법에 따라 달라지므로, 포장 식품은 제품 영양표시를 우선합니다.

이 계산기는 통계적 추정식에 기반한 **출발점**을 제시할 뿐입니다.
신장질환 · 당뇨 · 임신 · 수유 · 섭식장애 · 약물치료 중인 경우에는
이 가이드보다 의료진과 영양사의 개별 지도를 우선해야 합니다.
